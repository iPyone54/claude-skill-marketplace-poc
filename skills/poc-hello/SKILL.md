# poc-hello（配布検証用スキル）

プラグイン配布・更新反映の検証に使うスキル。呼び出されたら次の手順で応答する。

1. `references/version_info.md` を読む。
2. 挨拶に続けて、そこに書かれている「バージョン」「合言葉」「更新日」を一字一句そのまま表示する。
3. 最後に「このスキル本文のバージョン表記: 更新B」と表示する。

バージョン表記を SKILL.md 本文と references の両方に持たせているのは、更新がどのファイルまで反映されるかを切り分けるため。応答例は `examples/hello_sample.md` を参照。
