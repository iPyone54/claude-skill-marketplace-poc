# claude-skill-marketplace-poc

Claude のプラグインマーケットプレイス機能によるスキル配布・自動更新を検証するためのリポジトリ。中身はすべて検証用のダミースキルで、実データ・実業務の情報は含まない。

## 構成

リポジトリ全体を1つのプラグイン（poc-skills）として配布する。`skills/` 直下のディレクトリ1つが1スキル。

```
.claude-plugin/
├── marketplace.json   マーケットプレイスの目録
└── plugin.json        プラグイン定義（バージョンを持つ）
skills/
├── poc-hello/         バージョン・合言葉を報告する（更新検証の主役）
├── poc-checklist/     チェックリストを表示する
└── poc-fortune/       今日の一言を表示する（更新検証で変更しない対照用）
```

各スキルの内部構成（SKILL.md / references / examples / scripts / tests）は、本番リポジトリのスキル構成に合わせている。

## 検証手順

### 1. マーケットプレイス登録（初回のみ）

Claude Desktop の「カスタマイズ > プラグイン > 追加 > マーケットプレイスを追加」で `iPyone54/claude-skill-marketplace-poc` を登録し、poc-skills をインストールする。

### 2. 更新Aの確認

Cowork で「poc-hello を使って」と依頼し、応答に以下が含まれることを確認する。

- バージョン: 更新A
- 合言葉: りんご

### 3. 更新Bの配信

GitHub 上で `update-b` ブランチから `main` へのプルリクエストを作成してマージし、マージ時刻を記録する。

### 4. 更新Bの反映確認

Cowork で再び poc-hello を呼び出し、応答が以下に変わるまでの流れを観察する。

- バージョン: 更新B
- 合言葉: バナナ

確認ポイント:

- 更新の通知が表示されるか、セッションの開き直しが必要か、手動の更新ボタンが必要か
- マージから反映までの所要時間
- poc-fortune（更新Bで変更していない対照用スキル）の応答が変わらないこと

### 5. 組織配布の確認（管理者と実施）

claude.ai の「Organization settings > Plugins」でこのリポジトリを接続し、「既定でインストール」に設定した場合に他メンバーの環境へ自動配布されるかを確認する。
